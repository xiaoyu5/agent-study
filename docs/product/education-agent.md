# 教育 Agent：产品与首课范围

版本：0.1，2026-09-17。用户已确定：教育方向、首课贝叶斯思维、Python，以及人类与 AI 共同 Lead、AI Develop 的协作方式。以下学习流程和范围是本轮方案，尚未经过真实学习者验证。

## 产品目标

帮助学习者理解一个复杂理论，解释其原理与适用条件，并在自己的领域中独立应用。用学习者的作答与推理作为理解证据，而非以阅读时长、聊天长度或“听懂了”的反馈判断掌握。

首批用户暂按中文成年非专业学习者设计，具备基本比例和百分数知识；这是可调整的试点假设。先服务一个学习者、一节短课，不建设课程市场、多人课堂或完整学科平台。

## 第一课

课程方向：概率与决策。首节：**新证据如何改变判断——贝叶斯更新与基准率**。

首课只处理二元假设与一次证据更新。学习者应能：

1. 区分先验 `P(H)`、证据在假设成立时出现的概率 `P(E|H)`、后验 `P(H|E)`。
2. 用自然频数或公式解释为何需要同时考虑真实命中和误报。
3. 在未见过的新题中正确更新判断，并解释结果。
4. 在自己的领域识别假设、证据、所需数据及不足之处，不编造概率。

“更新判断”与“决定采取什么行动”分开。概率更新本身不能决定行动；行动还涉及收益、损失和约束。完整决策理论、连续分布、多重证据与相关性建模留到后续课程。

## 一个具体学习过程

例题为原创虚构教学情境：某批 1,000 件产品中，100 件有缺陷。检测器对缺陷品的报警率为 80%，对无缺陷品的误报率为 10%。收到报警后，产品有缺陷的概率是多少？

完整讲解：100 件缺陷品中 80 件报警，900 件无缺陷品中 90 件报警；报警总数 170，故答案为 `80 / 170 = 8 / 17 ≈ 47.06%`。检测器的 80% 命中率与报警后的缺陷概率是不同条件下的概率。

先使用人数/件数与简单表格理解分母，再引入公式；之后换数字与情境测试独立理解。本例假设比例适用于同一批次、类别互斥且穷尽，且报警事件概率大于零。不能将这个虚构比例当成真实业务数据。

| 环节 | 学习者做什么 | Agent 的职责 |
| --- | --- | --- |
| 目标与诊断 | 描述自己的领域，回答少量先备题 | 发现百分数、条件方向或基准率上的困难 |
| 解释与示例 | 阅读短解释，观察完整推理 | 选合适表达方式，说明类比与真实概念的对应及限制 |
| 重述与练习 | 用自己的话解释，尝试新题 | 根据具体错误给提示；必要时直接示范 |
| 独立检查 | 不看提示完成未见题 | 保存首答、理由、提示记录，区分独立与辅助完成 |
| 迁移 | 将理论映射到自己的问题 | 检查变量、证据来源和假设；缺数据时帮助列采集计划 |
| 回顾 | 说明已理解之处与疑问 | 生成有证据的学习记录，后续回访复测 |

环节允许回退、跳过已掌握内容和暂停；不是每次都强制走完。用户请求解释或明显卡住时直接讲解，避免无限反问。

## MVP 用户故事与验收

- 作为学习者，我可以暴露“不知道”和错误想法，得到针对性的解释，而非被要求猜模型想要的答案。
- 我可以看见自己的推理哪里错了，并在另一道题独立重试；系统不会把看过答案后的复述计作独立掌握。
- 我可以带入自己的场景，得到一份假设、证据、计算或缺失数据清单。缺数据时输出“暂不能算”也可能是正确结果。
- 我可以暂停，并在后续恢复同一课程版本的学习记录。
- 作为 Lead，我们可以回看模型动作、工具结果、提示与评分依据，复核错误结论。

工程验收和学习效果评估分别见 [开发路线](../engineering/development-plan.md) 与 [评估方案](evaluation.md)。本轮骨架仅支持课程结构检查与查看，尚未实现以上完整用户故事。

## 内容与使用边界

课程知识使用可核查资料、原创解释和经审核题目。课程包与题库按版本管理；模型可调整表达和反馈，但不能自行改标准答案或宣布课程已审核。

初期由本地课程包提供知识；用户带入的领域描述是待核实材料。首课不需要上传个人敏感资料，也不代替用户作现实世界的重要决策。课程内容、练习和验收题分开管理，最终验收题答案不进入导师的自由检索上下文。

## 教学依据与尚待验证的假设

示例与练习交替、主动回忆、解释性提问以及具体和抽象表示结合，参考 [IES 学习实践指南](https://ies.ed.gov/ncee/wwc/PracticeGuide/1)。指南中不同建议的证据强度不同，也不是对本产品的效果认证。

课程知识参考 [MIT 18.05 的条件概率及贝叶斯更新材料](https://ocw.mit.edu/courses/18-05-introduction-to-probability-and-statistics-spring-2022/pages/classes-reading-and-in-class-materials/)；[Brown Seeing Theory](https://seeing-theory.brown.edu/bayesian-inference/index.html) 可作为可视化补充，该站目前标记为归档。当前仅建立来源索引与原创草稿，没有复制课件或宣称内容审核已完成。

建议试点时观察：普通学习者是否能独立做新题，是否能正确识别自己领域的数据缺口，以及交互是否造成挫败。具体课时、适用人群和上线界面根据反馈调整。
