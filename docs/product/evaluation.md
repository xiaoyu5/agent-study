# 学习效果与 Agent 质量评估

版本：0.1，状态：试点评估设计；没有实验结果。课程和评分标准变化时必须记录版本，不能修改验收标准来掩盖一次失败。

## 三类评估分开

| 层次 | 核查内容 | 执行者 |
| --- | --- | --- |
| 工程正确性 | 课程引用、工具协议、预算、错误恢复、会话隔离 | 确定性测试与 AI Lead |
| 教学行为 | 错误反馈是否正确、提示是否合适、是否泄露答案、依据是否真实 | 固定对话样本 + AI 初评 + 人类 Lead 复核 |
| 学习结果 | 无提示的新题、跨情境应用、延迟保持 | 学习者真实作答 + 可计算校验 + 人工评分 |

生成几个成功对话不代表学习效果成立。模型对自己回答的评分也不能替代独立验收。

## 测量流程

1. 前测：等难度题，记录首答、理由和信心；不先给解法。
2. 学习：记录所见例题、作答、错误和提示等级；辅助完成单独标识。
3. 即时后测：未见过的无提示题，另行记录独立表现。
4. 近迁移：换情境和数字，但保留贝叶斯更新结构。
5. 领域迁移：学习者自己提出应用，并解释为什么适用、缺什么数据。
6. 延迟复测：初期建议约 7 天后用不同题回访。这个时间是试点安排，不是已证明的最优间隔；本轮不创建自动提醒。

用户在测验中请求提示时可以获得帮助，但该次转为辅助练习，换一道未见题才能再次收集独立作答证据。提示、看答案后重答与独立首答不得混为一条记录。

提示等级统一为 `none`（无帮助）、`conceptual`（指出概念）、`step`（给关键步骤）、`solution`（给答案或完整示范）。后三者均为辅助；保存每次提示，并以本次作答前已见的最高等级标记该次作答。

## 迁移评分表

每项 0–2：0=缺失或错误，1=部分正确，2=完整正确。是否独立完成用单独字段记录。初期展示分项与证据，不输出伪精确的“掌握百分比”。

| 维度 | 满分证据 |
| --- | --- |
| 适用性 | 识别可更新的假设与观察，说明为何使用贝叶斯 |
| 概念映射 | 正确区分先验、`P(E|H)`、`P(E|非H)` 和后验 |
| 推理与计算 | 解释分母，正确计算；信息不足时明确缺失量而非编数字 |
| 条件与边界 | 说明数据是否适用于目标群体、证据是否可靠，不把条件概率倒置 |
| 应用与检验 | 说明还要收集什么证据、如何验证；区分概率与行动成本 |

建议首课完成条件：独立新题的概念映射与推理均为 2；能说明至少一项有效边界；领域迁移给出可检查的结构或正确的数据缺口分析。该条件是 v0.1 产品规则，需人类 Lead 审核并在试点后修订，不是通用教育标准。

数值完整题的初始评分锚点：概念映射 0=倒置条件，1=认出先验但未区分误报与命中的条件，2=准确区分两个条件概率与后验；推理 0=直接将命中率当后验，1=分母结构正确但计算错误，2=分母和数值均正确。缺数据题使用单独答案锚点，准确指出具体缺失量可得满分。M2 实现评分前补齐各题各维度的正反例并由 Lead 审核。

近迁移、用户领域建模与延迟复测分别报告。提出领域应用与数据缺口先记作建模证据，不据此宣称现实任务中的远迁移已经得到验证。

## 首批评估集

先编写并人工核验约 12 个案例：4 个数字更新题、3 个常见误解题、3 个迁移/缺数据题、2 个工具或上下文异常题。题目、答案、评分标准和用途分别标识；训练用讲解、开发回归、最终保留题不能随意混用。

必须覆盖：把 `P(E|H)` 当成 `P(H|E)`、忽略基准率、遗漏误报、分母为零、缺失参数、把同一证据重复计入、没有成本信息却推导行动结论。数值题采用确定性校验并明确容差；分母为零应返回“在给定模型下无法条件化”，不能给出后验数值。

数值判断优先由程序完成。自由解释与领域迁移可由独立模型按版本化 rubric 提出评分，并附原文证据；低置信度、评分分歧和明显误解交人类复核。前期保留题逐条人工复评。

## 基线、指标与发布检查

基线：同一套静态解释与练习材料。先确定普通材料的表现，再判断自适应交互是否值得其复杂度。试点可先做少量成年人可用性与前后测；这只能提供可行性信号，不能据此宣称因果增益或远迁移已经得到证实。

分别报告：独立新题表现、提示次数、核心误解、迁移分项、延迟复测表现、退出情况、评分分歧、单次成本和运行失败率。没有参与复测的人应记作缺失，不能自动视为成功或失败。

初期工程门槛：确定性回归全通过；被验收样本中没有未解决的错误公式、错误标准答案或越权操作；关键评分分歧已经复核。尚未设置面向总体人群的学习增益目标；需要真实基线后再定。
